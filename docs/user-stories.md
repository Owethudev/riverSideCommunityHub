# Initial User Stories

- As a visitor, I can learn what the hub offers and find public contact or participation paths.
- As a visitor, I can view available facilities and understand how to request a booking.
- As a visitor, I can register an account and log in securely.
- As a member, I can view and update my profile.
- As a member, I can submit and review facility bookings.
- As a member, I can see the status of my bookings and donation activity.
- As staff, I can review booking requests and manage their status.
- As staff, I can manage members, donations, resources, and programmes.
- As an administrator, I can oversee hub activity and manage staff-owned records.
